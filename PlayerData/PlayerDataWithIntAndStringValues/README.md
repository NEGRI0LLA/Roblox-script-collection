# ENG:
### This folder contains data scripts for player any count of values and change string value when it change. 
* **Leaderstats** script creates currency values for the player.
* **DataScript** creates player values and includes a data saving system.
* **ChangeRankScript** changes a rank when player get needed count of money.

### Installation:
* Put **Leaderstats** or **DataScript** into the **ServerScriptService** folder.
* Put **ChangeRankScript** into the **ServerScriptService** folder.


# RU:
### Эта папка содержит скрипты для работы с данными и валютами игрока игрока и меняет ранк игрока при достижении определенного количества денег.
* Скрипт **Leaderstats** создает базовые параметры (валюту) для игрока.
* Скрипт **DataScript** отвечает за создание параметров игрока и систему их последующего сохранения.
* Скрипт **ChangeRankScript** меняет ранк при достижении определенного денежного количества.

### Установка:
* Положите **Leaderstats** или **DataScript** в папку **ServerScriptService**.
* Положите **ChangeRankScript** в папку **ServerScriptService**.
