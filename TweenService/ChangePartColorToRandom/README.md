# ENG:
### This script automatically creates a part in the Workspace and changes its color to a random one smoothly and infinitely using TweenService.

### Installation:
* Put this script into the **ServerScriptService** folder.

# RU:
### Этот скрипт автоматически создает блок (Part) в Workspace и плавно изменяет его цвет на случайный до бесконечности с помощью TweenService.

### Установка:
* Положите этот скрипт в папку **ServerScriptService**.
