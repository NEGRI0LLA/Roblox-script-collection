# ENG:
### This script automatically creates two parts in the Workspace (Blue and Red) that teleport the player between them when touched by their right foot. It also includes a 1.5-second cooldown to prevent infinite looping.

### Installation:
* Put this script into the **ServerScriptService** folder.


# RU:
### Этот скрипт автоматически создает два блока в Workspace (синий и красный), которые телепортируют игрока между собой при касании правой ногой. Скрипт также содержит задержку (cooldown) в 1.5 секунды для предотвращения бесконечного цикла телепортации.

### Установка:
* Положите этот скрипт в папку **ServerScriptService**.
