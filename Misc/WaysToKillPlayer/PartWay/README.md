# ENG:
### This script automatically creates a red neon part in the Workspace. When a player touches it with their foot, their character dies.

### Installation:
* Put this script into the **ServerScriptService** folder.

---

# RU:
### Этот скрипт автоматически создает красный неоновый блок (Part) в Workspace. Когда игрок наступает на него ногой, его персонаж умирает.

### Установка:
* Положите этот скрипт в папку **ServerScriptService**.
